# What Is Software?

Software is a collection of programs, instructions, and related data that tells a computer or other digital device what to do. Unlike hardware, software is not a physical part that you can touch. A computer's operating system, a web browser, and a calculator app are all examples of software.

Software and hardware work together: hardware provides the physical equipment, while software gives it instructions and helps people use it.

## Main Types of Software

Software is commonly grouped by its purpose. Some products fit into more than one category, and there is no single list that covers every possible kind.

### 1. System Software

System software manages the computer's hardware and provides a platform on which other programs can run.

Examples:
- Operating systems such as Windows, macOS, Linux, Android, and iOS
- Device drivers that let the operating system communicate with hardware such as printers, keyboards, and graphics cards
- System tools that manage files, memory, devices, and other computer resources

Without system software, most application programs would not be able to use the computer's hardware.

### 2. Application Software

Application software helps users perform particular tasks. It may be installed on a device or accessed through a web browser.

Examples:
- Word processors and spreadsheets
- Web browsers and email programs
- Image, audio, and video editing programs
- Games
- Accounting, banking, and business applications
- Mobile apps for communication, shopping, or learning

Application software may be general-purpose, such as a text editor, or special-purpose, such as software for managing a hospital.

### 3. Programming and Development Software

Programming software helps people create, test, and maintain other software.

Examples:
- Code editors and integrated development environments (IDEs)
- Compilers that translate source code into a form a computer can execute
- Interpreters that run instructions in a programming language
- Debuggers that help developers find and investigate errors
- Build and version-control tools

Examples of development tools include Visual Studio Code, compilers, and Git.

### 4. Utility Software

Utility software performs maintenance, protection, or management tasks for a computer. It is often considered a category of system software.

Examples:
- Antivirus and security tools
- Backup and restore programs
- File compression and extraction tools
- Disk cleanup and storage-management tools
- File search and recovery tools

Utilities help keep devices secure, organized, and working efficiently.

### 5. Firmware

Firmware is specialized software stored in or close to a hardware device. It provides basic instructions for that device, often starting it up and controlling its essential functions.

Examples:
- The startup software in a computer's motherboard
- Software inside a router, printer, or smart television
- Control software in household appliances

Firmware is often stored in non-volatile memory, so it remains available when the device is turned off. It can sometimes be updated.

### 6. Middleware

Middleware is software that helps separate applications, services, or systems communicate and work together.

Examples:
- Software that connects an application to a database
- Message-broker software that passes information between services
- Web and application servers that handle requests from other programs

Middleware is commonly used in business systems and distributed applications.

## Other Ways to Classify Software

These classifications describe how software is delivered or licensed; they are not separate replacements for the purpose-based types above.

### By delivery method

- **Desktop software:** Installed and run on a personal computer.
- **Mobile software:** Designed for phones or tablets.
- **Web application:** Used through a web browser, often with some processing on a remote server.
- **Cloud or Software as a Service (SaaS):** Hosted by a provider and accessed over a network, usually through a browser or app.
- **Embedded software:** Runs as part of a device or product, such as a vehicle or appliance.

### By license and access

- **Open-source software:** Its source code is made available under a license that grants specified rights to use, inspect, modify, or distribute it.
- **Proprietary software:** Controlled by its owner and used under the terms of its license; its source code is usually not publicly available.
- **Freeware:** Available to use without a purchase price, but it may still be proprietary.
- **Shareware or trial software:** Distributed for evaluation or limited use; payment may be required for continued or full use.

“Free” can mean free of charge or freedom to use and modify the source code; those meanings are not always the same.

## Quick Comparison

| Type | Main purpose | Example |
|---|---|---|
| System software | Manages hardware and provides a platform | Operating system |
| Application software | Helps users complete tasks | Spreadsheet app |
| Programming software | Helps create and test programs | IDE or compiler |
| Utility software | Maintains or protects a device | Backup tool |
| Firmware | Controls a particular hardware device | Router software |
| Middleware | Connects applications or services | Database connectivity software |

## Conclusion

Software is the set of instructions and related data that make digital devices useful. Its main purpose-based types are system software, application software, programming software, utility software, firmware, and middleware. Software can also be classified by how it is delivered and by its license. The right type depends on what the user or device needs to do.
