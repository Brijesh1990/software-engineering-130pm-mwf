# what is html ?
- html stands for hypertext markup language
- html used to create webpage for website
- html first time release in 1986 by **tim berner lee**
- html file extension .html or .htm
- html is not any language it is a markup language that can be used to create website
- html is a case-insenstive language
**examples**
  1. <html> or <HTML> or <Html>
- html provides its own structures for create webpage
- basic structures of html is ?
- html **structures**
- html **boiler plate**
- html **skelton** 

**create a webpage**
```
structure.html

<!DOCTYPE html>
<html>
<head>
<title>First web page</title>
</head>
<body>
<h1>THis is Swara</h1>
</body>
</html>
```
